# Publier un article sur le site du PCRF

Ce guide s'adresse aux rédacteurs et rédactrices. Il tient en une page.

## 1. Se connecter

Ouvrez l'adresse du site suivie de `/admin` (par exemple `https://www.pcrf-ic.fr/admin`).
Saisissez votre adresse mail et votre mot de passe. Si vous l'avez oublié, cliquez sur « Mot de passe oublié ».

## 2. Écrire un article

Dans le menu de gauche, cliquez sur **Articles**, puis sur **Créer**.

| Champ | Quoi mettre |
|---|---|
| **Titre** | Le titre de l'article. Dites le sujet : « Grève à Sanofi : soutien aux grévistes » plutôt que « Communiqué ». |
| **Chapeau** | Deux ou trois phrases de résumé. Elles s'affichent dans les listes et en tête de l'article. |
| **Image principale** | Une photo ou une affiche. Glissez le fichier dans la zone, ou choisissez une image déjà envoyée. |
| **Texte** | Le corps de l'article. La barre d'outils permet gras, italique, titres, listes, liens et images. |
| **Documents joints** | Un tract, une affiche ou une brochure en PDF à proposer en téléchargement. |
| **Vidéo YouTube** | Pour la rubrique Vidéos : collez le lien de la vidéo. |
| **Rubrique** (à droite) | Obligatoire : France, International, Luttes, Journal, Campagnes, Vidéos, Théorie, Matériel… |
| **Date de publication** | Proposée automatiquement. Modifiez-la pour antidater ou programmer. |
| **Mettre à la une** | Cochez pour afficher l'article en grand en haut de l'accueil. |

Vous pouvez coller un texte venant de Word ou de LibreOffice : la mise en forme de base est conservée.

## 3. Enregistrer ou publier

En haut à droite :

- **Enregistrer le brouillon** : l'article est gardé mais reste invisible sur le site. Vous pouvez y revenir plus tard.
- **Publier** : l'article est en ligne immédiatement.

Pour retirer un article publié, ouvrez-le, puis dans le menu « … » choisissez **Dépublier**. Pour le modifier, changez le texte et cliquez à nouveau sur **Publier**.

## 4. Les images

- Formats acceptés : JPG, PNG, PDF. Le site redimensionne les images tout seul.
- Dans **Médias**, vous retrouvez tout ce qui a été envoyé. Vous pouvez réutiliser une image dans plusieurs articles.
- Pensez à remplir « Description de l'image » : c'est ce que lisent les personnes malvoyantes et Google.

## 5. Retrouver un article

Dans **Articles**, la case de recherche cherche dans les titres et les chapeaux. Les colonnes peuvent être triées par date ou par rubrique. Les articles de l'ancien site sont tous là, avec leur date d'origine.

## 6. Qui peut faire quoi

- **Rédacteur** : écrire, publier et modifier des articles, envoyer des images.
- **Administrateur** : en plus, gérer les rubriques, les menus, les pages fixes (Qui sommes-nous, Programme, Contact, Don), les réglages du site et les comptes.

## La fenêtre « Programme » de l'accueil

Dans **Page d'accueil › Programme**, un administrateur peut changer le fichier PDF, le titre, le texte et les **pages d'aperçu** : 2 ou 3 images de pages (par exemple la couverture et une page intérieure). Elles s'affichent comme des feuilles posées dans le bloc rouge, qui se soulèvent quand on survole la fenêtre. La première image est devant. Pour obtenir l'image d'une page à partir du PDF : ouvrir le PDF, faire une capture d'écran de la page (ou « Exporter en image » dans Aperçu), puis l'envoyer dans le champ.

Les réglages du site (bandeau, réseaux sociaux, lettre d'information, HelloAsso, fenêtres de l'accueil) sont dans le menu **Structure** › **Réglages du site** et **Page d'accueil**.

## En cas de problème

Rechargez la page. Si un message d'erreur persiste, notez l'heure et ce que vous faisiez, et prévenez l'administrateur du site.
